The **BridgeX** asset collection spans two directories in the repository. The versioned project logo lives in `dev2forge/logos/` alongside the other Dev Forge project logos, while the three application UI screenshots are stored in `dev2forge/bridgex/`. Together these assets are used in the BridgeX README, release notes, and documentation pages to showcase the application's main interface, its LLM configuration panel, and its Markdown rendering capability.

## Logo

| File | Format | CDN URL | Description |
|------|--------|---------|-------------|
| `bridgex-v0.1.0.webp` | WebP | [CDN](https://cdn.jsdelivr.net/gh/tutosrive/images-projects-srm-trg@main/dev2forge/logos/bridgex-v0.1.0.webp) | Official BridgeX logo, version 0.1.0 |
