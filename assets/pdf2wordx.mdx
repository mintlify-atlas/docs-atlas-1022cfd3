The **PDF2WordX** (pdf2wordx) asset collection is structured by release version so that each generation of the application can be referenced independently. Images for four releases are stored under `img-pdftoword/`, the canonical vector logo lives in `dev2forge/logos/`, and a sample document conversion preview resides in `pdf2docx/`. These assets appear in release changelogs, README files, and marketing pages to illustrate how the application's interface has evolved across versions. All files are delivered via the jsDelivr CDN.
