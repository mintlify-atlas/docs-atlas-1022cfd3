The `dev2forge/InitVenv/` directory holds every visual asset published for the **InitVenv** project — a Python virtual-environment initialiser tool. The collection covers the project's branding (SVG logo and `.ico` icon), illustrative screenshots that appear in the documentation and README, problem-state captures used in the troubleshooting guide, and a full animated GIF walkthrough of the tool in action. All files are delivered over the jsDelivr CDN and can be embedded in any Markdown, HTML, or React context.
