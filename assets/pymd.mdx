The **PyMD** asset tree covers three sub-directories under `dev2forge/pymd/`. The root contains the main project logo and a `previews-beta/` folder with early-access screenshots. The `bridge/` sub-directory holds five numbered UI screenshots for the **PyMD Bridge** variant, documenting the main view, file-open dialog, mini-editor, conversion panel, and language-change screen. The `bridgex/` sub-directory mirrors that same five-screenshot layout for **PyMD BridgeX** and also includes an animated logo in WebP format. All assets are served from the jsDelivr CDN.
