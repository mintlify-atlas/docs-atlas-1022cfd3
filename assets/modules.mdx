The `modules/` directory contains logos, animated demonstrations, and web-page preview screenshots for the Python package ecosystem published under the Dev Forge umbrella. The primary modules covered are **ChromoLog** (a coloured console logger), **ChromoLogger** (an extended logging library), **SQLazo** (a lightweight SQLite ORM), and **ChronoLogger** (a time-stamped logger). Versioned logo badges for these modules are also stored in `dev2forge/logos/`, providing a canonical branding reference for each release. All files are served via the jsDelivr CDN.
