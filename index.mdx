## How CDN Delivery Works

<Steps>
  <Step title="Find your asset path">
    Browse the [Asset Catalog](/assets/initvenv) to locate the file you need. Each page lists the repo-relative path for every asset.
  </Step>
  <Step title="Construct the CDN URL">
    Prepend the jsDelivr base URL to any file path:
    ```
    https://cdn.jsdelivr.net/gh/tutosrive/images-projects-srm-trg@main/<path/to/file>
    ```
  </Step>
  <Step title="Use a pinned SHA for stability">
    For production use, replace `@main` with a specific commit SHA to get an immutable, cached URL that never changes:
    ```
    https://cdn.jsdelivr.net/gh/tutosrive/images-projects-srm-trg@<commit-sha>/<path/to/file>
    ```
  </Step>
</Steps>
